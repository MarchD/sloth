Use the `decider` skill. Ask the user for:
1. **Topic** — one short phrase (becomes part of the filename and title)
2. **Context** — what problem this addresses
3. **Options** considered (briefly)
4. **Decision** — what was chosen
5. **Consequences** — good and bad

Then `decider` produces the ADR file (preview before write).
